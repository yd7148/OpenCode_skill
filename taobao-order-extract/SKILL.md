# 淘寶訂單資料提取與整理

## 目的
將淘寶匯出的訂單 Excel（`訂單數據.xlsx`）整理成依序編號的 markdown 訂單卡片，每個卡片包含商品名稱、實付金額、物流公司與單號，並比對物流重量清單補上對應重量。

## 輸入
1. **訂單 Excel**：`訂單數據.xlsx`（sheet 名稱通常為「訂單數據」，含表頭）
2. **物流重量清單**（選用）：純文字/表格，格式為「物流單號 + 目的地（台灣）+ 重量」，例如 `79027852606958 台灣 1.260`

## 訂單 Excel 欄位
訂單 Excel 每列依序為：
`訂單號, 訂單提交時間, 訂單狀態, 店鋪名稱, 商品名稱, 商品連結, 型號款式, 商品數量, 商品金額, 實付金額, 運費, 物流公司, 物流單號`

### 重要處理規則
- **分組**：同一訂單可能有多列（多個款式/尺寸）。判斷依據：若「訂單號」欄為空 `None`，則該列屬於上一筆有訂單號的訂單。每個「訂單號」視為一筆獨立訂單。
- **商品名稱**：取該訂單第一列（訂單號那列）的「商品名稱」。
- **實付金額**：取該訂單第一列的「實付金額」（即「訂單號」所在列的實付金額），而非子列。
- **物流**：使用「物流公司」與「物流單號」欄位。
- **交易關閉**：若訂單狀態為「交易關閉」，則無物流公司與單號，標記為 `(交易關閉)`。

## 輸出格式
每筆訂單為一個 markdown 段落，依序編號（`#01`, `#02`, ...）。欄位之間以空行分隔，欄位結尾加兩個空格（強制換行），確保 markdown 正確顯示換行與縮排：

```
## #01

商品名稱  
實付金額 ￥6.80  
极兔速递 JT3175068909140  
JT3175068909140 台灣 0.180
```

### 重量比對
若提供了物流重量清單：
- 解析出 `{物流單號: 重量}` 對照表。
- 在每個訂單的物流單號之後，追加一行 `物流單號 台灣 重量`（如範例）。
- 若物流單號在重量清單中查無資料，則不追加重量行。
- 重量清單中出現但訂單中不存在、無法對應的單號，在最終輸出時提示使用者（例如 `SF5118589082120` 無對應訂單）。

## 步驟
1. 用 Python + openpyxl（安裝於專用 venv）讀取 `訂單數據.xlsx`。
2. 依「訂單號」欄位將列分組成獨立訂單。
3. 取出每筆訂單的商品名稱、實付金額、物流公司、物流單號。
4. （選用）解析物流重量清單，建立單號→重量對照。
5. 依序輸出 markdown 卡片，若使用者要求則存成 .md 檔（例如 `訂單數據整理.md`）。

## 注意
- 若結果筆數與使用者預期（如 25 筆）不符，主動說明實際筆數（例如只有 20 筆）。
- 輸出的商品名稱、金額等保留原文（簡體中文），標題與重量「台灣」用繁體。
- 金額保留 `￥` 符號原樣。
